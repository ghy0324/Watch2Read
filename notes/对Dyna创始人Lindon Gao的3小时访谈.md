## “我们是蟑螂，我们死不了”：连续创业经历

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=101">中美机器人观察与Dyna的全栈定位</a> `01:41`

<details>
<summary>Lindon认为两地同样热闹，但对核心瓶颈的判断不同。</summary>

- Lindon每年到中国约一两次，Dyna在上海有团队；他感到当地机器人发展快、竞争激烈。
- 他认为中美行业都有浮躁的一面，频繁发布新品、争取更多融资，短期氛围颇为相似。
- 在其概括中，美国较偏“大脑派”，相信智能是核心问题，身体会逐步解决；中国较偏“身体派”，重视供应链，相信模型会跟进。
- 他也注意到国内近来已加强模型布局，因此这只是趋势概括而非绝对划分。
- Dyna自我定位为全栈派，不将智能与硬件中的任一环节视为可以完全交给别人解决的问题。

</details>

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=189">14岁开始做生意：喜欢做对事情的回报</a> `03:09`

<details>
<summary>早期环境让Lindon熟悉交易，商业兴趣早于正式创业。</summary>

- Lindon在中国出生，11岁赴美，身边不少人经营小买卖，较早受到创业型环境影响。
- 他14岁时做第一门生意，买卖游戏账户、装备，并建立交易平台，也在其他平台或论坛交易。
- 这门生意赚到上万美元，后来热度下降，他把网站出售。
- 早期并非只做一个项目，还零散卖过软件、鞋子等，跟随身边人的商业潮流学习如何赚钱。
- 他认为自己并不只是喜欢钱，而是喜欢做对一件事情后获得回报的感觉；当时没有特别专注课业。

</details>

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=347">珠宝库存与跨境设计师供应链</a> `05:47`

<details>
<summary>Lindon把费时的零售转为连接中国供应链和美国设计师的企业生意。</summary>

- 大学二年级时，他发现一些原本准备熔化回收金属的珠宝库存，尝试买入并在eBay出售，销量逐渐形成生意。
- 通过家庭和朋友，他接触到中国珠宝供应链；通过美国朋友，了解当地需求。
- 零售需要每日包装、处理反馈，与上课和实习冲突，于是他将业务从2C转成2B。
- 目标客户变为美国珠宝设计师，帮助解决当地制作昂贵、打磨和量产能力不足的问题，以供货获得收益。
- 后来业务可由亲属管理，他每周花三四小时，口述每年约赚十几二十万；这段金额没有再次明确币种。
- 业务持续十年左右，最终由他主动结束，因为当前更重要的事情使这点时间投入不再划算。

</details>

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=495">从医学、金融到投行再到创业</a> `08:15`

<details>
<summary>Lindon的路径多次转向，选择投行也包含跟随同学竞争的成分。</summary>

- 他认为父母总体较放手，让自己选择喜欢的事，但最初学医确实受父母意愿影响。
- 在纽约大学学习约两年医学相关课程后，他不想继续，转向金融。
- 他承认起初并不了解投行，只看到商学院同学都想进入，便想与大家竞争，后来在那里工作两年多。
- 离开投行后，他直接创业，创建Dyna以前的项目Caper，并将其称作“半个机器人”。

</details>

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=593">走访150家超市后，否定整店改造</a> `09:53`

<details>
<summary>技术很酷不等于客户愿意购买，Caper从实际ROI重新定义产品。</summary>

- 2017年前后Amazon Go使无人零售受到关注，通过整店传感器和视觉追踪实现拿走商品后自动结账。
- Lindon回忆中外当时出现数十家同类公司，热度类似今天机器人赛道，Caper后来成为少数幸存者之一。
- 别人多把传感器放在货架、摄像头装在天花板，Caper却先向超市询问真实需求。
- 他称访问了约150位超市老板，竟没有人愿意采用类似方案，甚至免费提供也不愿意。
- 客户认为花几十万只节省几个收银员缺少回报，而收银员本来还承担其他工作。
- 重新装修、维护技术又带来成本与干扰，Lindon因此判断原有产品的商业逻辑可能走不通。

</details>

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=723">把问题缩小到购物车</a> `12:03`

<details>
<summary>购物车以更简单的系统回答谁付钱、付多少钱两个核心问题。</summary>

- Caper将传感器融合和视觉识别集中在购物车内，而不是重新布置整个商店。
- Lindon把无人结账拆成两个问题：谁付款，以及应付多少钱。
- 购物车与使用者绑定即可确定付款人，识别车内放入的商品即可确定金额。
- 这种设计目标不变，却显著降低了技术和部署复杂度，成为项目逐步落地的起点。

</details>

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=761">YC毕业后，靠低成本熬过两年半</a> `12:41`

<details>
<summary>知名导师并未直接解决融资难题，团队先以极低开销换取生存时间。</summary>

- Caper首次申请便进入YC，导师包括Sam Altman和Geoff Ralston，但Lindon称该批次结束后的融资成绩接近末尾。
- 团队当时只融资约30万美元，投资人持续质疑背景、成功依据，以及硬件的高成本和分发难度。
- Lindon向另外三位联合创始人说明无法发工资，提议同住一个房子，只支付房租、油费和自己做饭的伙食费。
- 四位联创加一两位早期员工以每月约7000美元开销运行，持续两年半才融到约200万美元种子轮。
- 缺钱之外，智能购物车本身也反共识：投资人更熟悉Amazon Go式路线，担心购物车将被淘汰。

</details>

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=936">从上千封冷邮件到A轮融资</a> `15:36`

<details>
<summary>融资没有一劳永逸的突破，硬件开发和超市销售周期使资金压力持续存在。</summary>

- 为撑到种子轮，Lindon给1000多位天使投资人发冷邮件，最终转化两位，每人约投5万美元。
- 他回忆当时账户只剩一两万美元，这笔资金帮助团队继续生存。
- 正式种子轮见过100多家机构，最后只有First Round Capital愿意投资。
- 硬件开发周期加上超市漫长的销售周期，使产品从落地到可扩展又花了一年半以上。
- 2019年A轮想融千万美元量级，见60多位投资人仍屡遭拒绝，最终由Lux Capital投入约一千多万美元。
- 到B轮时已有明显业务进展，团队拿到两份投资意向书和一份收购邀约，曾拒绝收购两次后才决定出售。

</details>

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=1051">从连续拒绝中修心，也学会倾听</a> `17:31`

<details>
<summary>Lindon后来意识到，融资失败不只是表达不足，还在于没有理解投资人的视角。</summary>

- 谈最痛苦阶段，他说越在低谷越需要修心，阅读《沉思录》也是其中的一部分。
- 被拒十次还能继续，连续一百次后则会怀疑自己或项目是否根本不行。
- 他把每次失败看作一次强化学习，问下次如何做得更好，因此最苦的阶段也是成长最快的阶段。
- 对于所谓投资人“思维画像”，他承认当时恰恰没有，只顾说而不顾听，没有与对方建立共同理解。
- Caper创业持续约六年；2021年出售时，他首先感到事情做对了，而不是突然有钱。
- 他提及约3.5亿美元的交易规模，表示放手的重要原因是希望把六年积累用于更大的事业，而非仅为套现。

</details>

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=1231">做本质、有价值的事情</a> `20:31`

<details>
<summary>Lindon警惕把招人、签单或融资当成可以绕过产品问题的捷径。</summary>

- 回顾前面两门生意和一次创业，Lindon最重要的经验是做最本质的事，过去走过许多不必要的弯路。
- 他反对“只要招到某个人，问题就解决”的招聘心态，也不认为拿下某客户必然就能获得融资。
- 产品的基础仍是实际价值，而不是技术是否足够酷。
- 他以无人零售为例，批评先拿着黑科技再寻找应用场景的“拿锤子找钉子”方式，接下来用购物车商业价值说明这一点。

</details>

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=1301">真实价值从省人工转向提高客单价</a> `21:41`

<details>
<summary>购物车屏幕产生了整店无人零售未充分利用的互动和广告机会。</summary>

- Lindon说开发中发现，购物车最大的价值不一定是节省收银人工，而是消费者与屏幕互动时产生的新增收入。
- 系统可根据已放入商品推荐相关商品，或提示再买几件便可获得优惠券，从而提高平均购物篮金额。
- 屏幕还带来广告机会，使产品商业价值进一步扩大，而纯粹无感离店方案缺少同样的互动界面。
- 这些价值来自实际做产品过程中的发现，并非最初仅凭无人零售技术想象就能确定。

</details>

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=1375">PMF必须经得起ROI和规模化检验</a> `22:55`

<details>
<summary>签下一个付费客户不等于成立的产品，硬件必须证明可持续回报。</summary>

- 若产品尚无合理ROI，多拿一个客户本身没有意义，除非明确知道规模扩大后回报会如何成立。
- Lindon认为不少机器人公司把客户愿意付款当作PMF，却忽略后续定制化、节拍等条件仍无法满足客户的实际价值要求。
- 在硬件机器人领域，他把ROI视为产品成立的基础，而不是融资或签单数量之外的附属指标。
- 回忆Sam Altman的指导，他说最清楚的要求是反复上线、迭代；当时每周大约见两次，自己未必能充分理解导师更深层的判断。

</details>

## “我可以闻得到钱”：商业判断与创业动机

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=1489">把创业者当作脑力运动员</a> `24:49`

<details>
<summary>稳定习惯是Lindon管理精力和注意力的方式。</summary>

- Lindon从创业早期开始通常五六点起床，六七点运动，晚上十至十一点左右睡觉，这种自律已积累约十年。
- 他借《Atomic Habits》的思路解释，持续的小习惯会逐渐把人塑造成想成为的样子。
- 他把创业视为脑力运动，认为饮食、睡眠和运动影响能否集中思考，因此对身体管理要求很高。
- 习惯建立后，执行不再占据过多心智资源，反而不运动时会感觉不适。
- 他个人晚餐较少吃碳水、饮食规律，并说部分习惯来自父亲的示范；这些是其个人实践，而非适用于所有人的健康建议。

</details>

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=1652">方向判断需要清醒状态</a> `27:32`

<details>
<summary>在找人、找钱、找方向中，Lindon尤其强调方向决策的思考质量。</summary>

- Lindon认为自律能帮助决策，CEO需要做本质、清晰、高质量的选择。
- 在找人、找钱、找方向的常见职责划分中，他认为方向问题尤其消耗深度思考能力。
- 要把事情想透，需要足够清醒的精神状态，而不能长期处于疲惫和模糊之中。
- 30岁出售公司时，他并不觉得人生已经完成，反而认为才刚开始。

</details>

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=1707">在Instacart学习组织中的资源争取</a> `28:27`

<details>
<summary>被收购后的三年，让Lindon补上自己早期野路子创业的管理短板。</summary>

- Caper被收购后，他在Instacart待了约三年，重要动机是向其中来自Uber、Facebook、Google等公司的高管学习。
- 他形容前三次经历较野路子，常根据自己对商业和产品的判断，直接带工程团队去做。
- 过去最大盲点之一在产品管理及更大组织中的协作，因此他希望在成熟公司观察另一套方式。
- 他学会向CEO争取资源时，不只说项目重要，还要合理组织表达、理解对方底层动机，并与之对齐。
- 这与融资有相似处，但在公司内与CEO频繁互动，使这项能力得到更持续训练。

</details>

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=1859">岗位画像与人的能力边界</a> `30:59`

<details>
<summary>管理不能只凭喜欢某个人，还要明确职责及成长能否匹配。</summary>

- Lindon把这一类限制主要归因于预训练，认为只是为每个小任务继续补后训练数据不够。
- 预训练升级与整个工作流的产品目标互相牵引，构成Dyna后来更重预训练的原因。

### <a href="https://www.youtube.com/watch?v=iDaxRNIddME&t=4066">System 2、1、0：从理解到语言、动作和控制</a> `1:07:46`
