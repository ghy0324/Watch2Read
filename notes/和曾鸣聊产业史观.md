### <a href="https://www.youtube.com/watch?v=E7qB_p1D0Xk&t=188">战略研究的价值来自理论与高速增长实践的结合</a> `03:08`

<details>
<summary>曾鸣将自己的影响力归于阿里实践、学术训练和持续的前沿产业研究。</summary>

- 面对为何影响了许多创业者的提问，曾鸣首先强调幸运：他在互联网高速发展时期加入阿里，亲历一家公司的超高速增长。
- 学术训练使他能一边判断原有理论哪些可以应用，一边把实践中的新经验提炼成未来仍可使用的框架。
- 他持续研究前沿产业，因此与企业家的讨论不只涉及战略方法，也涉及行业接下来如何发展以及不同选择是否合适。

</details>

### <a href="https://www.youtube.com/watch?v=E7qB_p1D0Xk&t=266">阿里的三项关键战略与两项重要转型</a> `04:26`

<details>
<summary>淘宝、支付宝和阿里云的创立，在当时都不是没有争议的决定。</summary>

- 曾鸣回顾自己完整参与的阿里前十五年，将创立淘宝、支付宝、阿里云列为最重要的三项战略决定。
- 这些选择不仅当时不被外界普遍理解，在公司内部也有极其激烈的争论。
- 淘宝创立时，一些高管认为阿里原有业务尚未成熟，就去攻击 eBay 的核心业务，风险过大。
- 淘宝从买卖商品的平台转为支持电商发展的生态，以及全力转向移动互联网，也是他认为重要的战略变化。

</details>

### <a href="https://www.youtube.com/watch?v=E7qB_p1D0Xk&t=347">一个大方向之后，还有层层相互影响的决策</a> `05:47`

<details>
<summary>战略并非作出一次选择就结束，架构、场景和执行上的次级决策同样决定成败。</summary>

- 阿里云早期要决定先服务单一场景，还是从架构上支持多种场景；也要在淘宝、搜索等不同起点之间取舍。
- 开源还是闭源、是否自研数据库，都曾是有重大争论的次级战略问题。
- 计算、存储、数据库的改变彼此关联；当时的“去 IOE”对应替代 IBM、Oracle、EMC 等体系。
- 解决计算之后，存储又可能变成瓶颈；越深入执行，战略与战术越难割裂。
- 因此，作出宏观决策只是开始，从决定到执行再到结果，仍有巨大挑战。

</details>

### <a href="https://www.youtube.com/watch?v=E7qB_p1D0Xk&t=423">非共识不是成功保证，战略是创造未来</a> `07:03`

<details>
<summary>曾鸣强调非共识赢家背后的幸存者偏差，不能把反对共识本身当作方法。</summary>

- 被问到当时如何确定战略正确，曾鸣回答并不知道；团队基于自身能力，选择相信所能看见的未来图景。
- 他认为时代性公司的成功往往来自后来被证明正确的非共识，但许多同样疯狂的想法已经消失。
- 因此，“成功者往往非共识”不等于“非共识一定成功”，观察赢家时必须注意幸存者偏差。
- 在他的定义中，共识赛道中做得更好可以带来优秀；卓越则与创造此前不存在的未来相关。
- 战略不仅是规划既有资源如何分配，更大程度上是主动创造未来。

</details>

<details>

- 当他认为自己看清 AI 产业化所处阶段及各阶段的规则后，焦虑有所减少，并获得面向未来三至五年的行动框架。

### <a href="https://www.youtube.com/watch?v=E7qB_p1D0Xk&t=632">通用技术的三阶段：基础设施、应用繁荣、原生世界</a> `10:32`

<details>
<summary>曾鸣把技术产业化归纳为三个连续阶段，而非基础模型成熟后立即出现终局产品。</summary>

- 这一框架来自他对 PC、PC 互联网、移动互联网以及工业革命历史的比较研究，适用对象是具有广泛用途的颠覆性技术。
- 第一阶段是技术逐渐被社会接受，并成为社会基础设施。
- 第二阶段是在基础设施上产生海量新应用，进入百花齐放的时期。
- 第三阶段是大量应用反过来提出运行新世界所需的更底层方法，他称之为“原生应用阶段”。
- 他将移动互联网中的抖音、字节视为第三阶段的代表；这里的阶段划分是其分析框架，而非唯一行业分类法。

</details>

### <a href="https://www.youtube.com/watch?v=E7qB_p1D0Xk&t=710">黑莓、App Store 与抖音如何说明阶段更替</a> `11:50`

<details>
<summary>早期拥有巨大用户规模，不代表产品就是新技术的最终原生形态。</summary>

- 曾鸣以黑莓曾占据智能手机强势地位、iPhone 4 后苹果加速发展为例，说明早期领先者不等于最终主导者；他在节目中提到约 2010 年美国份额四成与两成的比较。
- iPhone 与 App Store 之后，出现过墨迹天气等快速获得大量用户的应用；早期规模本身不能证明它代表终局。
- 字节也先做内涵段子、今日头条等产品。早期文字技术成熟，形成了头条及推荐算法的技术和商业模式。
- 随着带宽、算力等条件成熟，短视频与推荐算法结合，才出现抖音这样的国民级应用。
- 应用繁荣为技术下一步的发展提供方向，基础设施成熟后仍会继续演化，无法事先完整知道哪种组合最终成立。

</details>

<details>
<summary>第二阶段可能很长且有独立价值，不能跳过实践积累直接抵达原生阶段。</summary>

- 主持人询问第二阶段是否只是过渡，曾鸣提醒，这种说法容易抹去这一阶段创业者的真实价值。
- 他认为第二阶段本身精彩而有价值，可能还会持续八年或十年；该时间是访谈中的估计。
- 第三阶段不能凭空跨越到达，必须经历第二阶段大量应用的积累。
- 对已经形成的基础设施，当下应做的是推动应用大爆发，而不是只追问遥远终局；他随后提出 2026 年可视为第一阶段基本完成的标志年份。

</details>

### <a href="https://www.youtube.com/watch?v=E7qB_p1D0Xk&t=908">Token 成为计量单位，是基础设施化的信号</a> `15:08`

<details>
<summary>当能力能够标准化计量、调用和计费，技术开始成为可规模使用的公共底座。</summary>

- 曾鸣以黄仁勋提出 Token 工厂、OpenAI 强调出售 Token 的讨论，解释自己为何判断第一阶段趋于成熟。
- 关键不只是出现一个术语，而是形成被广泛接受的计量方式，使技术能够标准化、规模化使用。
- 他将 Token 类比于度电、吨水、GB 流量：使用者能够围绕用量、完成的工作和成本来理解服务。
- 这一判断并不表示模型停止发展，智能仍会增强、成本仍会下降；改变的是商业模式和社会认知已形成相对稳定的基础。

</details>

### <a href="https://www.youtube.com/watch?v=E7qB_p1D0Xk&t=984">OpenClaw 展示的是独立完成任务的 Agent 潜力</a> `16:24`

### <a href="https://www.youtube.com/watch?v=E7qB_p1D0Xk&t=1078">从共享信息到共享能力</a> `17:58`

<details>
<summary>网站与 Skill 的类比，着眼于供给如何被数字化和复用，而非产品外形相似。</summary>

- 曾鸣注意到 Agent 与 Skill 同时出现：人们把自己会做的事情封装，让别人可以调用。
- 他回忆早期互联网建站热潮，其核心是把信息放到网上供人共享；本轮智能体热潮则是共享能力。

- 他强调历史类比应抽象出底层运行规律，不能只照搬技术的表面形式或机械对应年份。

</details>

### <a href="https://www.youtube.com/watch?v=E7qB_p1D0Xk&t=1175">浏览器同时降低创造端和使用端的门槛</a> `19:35`

<details>
<summary>统一标准和简单入口共同促成供需两侧爆发，随后才出现组织信息的新需求。</summary>

- 曾鸣认为浏览器及相关标准首先简化了网站制作，使有信息的人不再必须依赖专业工程师才能发布。
- 另一方面，用户通过点击即可浏览信息，使用门槛显著降低。
- 供给和用户同时增长，网站越来越多，用户开始需要知道哪些值得看。
- Yahoo 最初通过目录、精选和分类组织信息，作用在于降低信息爆炸后的认知负担。
- 他用“增熵与减熵”描述这组关系：新内容增加复杂度，组织和筛选又降低复杂度。

</details>

## 战略生成系统
