## 开场：用AI记录饮食、训练与身体数据

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=0">访谈开场与训练起点</a> `00:00`

<details>
<summary>孙宇晨把新开始的薄肌训练作为观察AI生活应用的具体案例。</summary>

- 节目预告围绕年轻人没有资源时如何重新开始，以及认知如何影响人生选择展开。
- 主持人邵艾伦介绍自己是口语内容创作者，也提出了薄肌训练理念；字幕中的“搏击”结合语境应为“薄肌”。
- 孙宇晨表示自己刚开始训练一天，希望在三至六个月后观察变化。
- 他自述身高约172厘米、体重约75公斤、体脂率约29%；这些是访谈中的个人数据。

</details>

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=93">饮食照片与日常训练记录</a> `01:33`

<details>
<summary>他把吃饭前后照片交给AI估算摄入，再与训练记录结合。</summary>

- 孙宇晨描述的新日程是起床后工作、吃第一餐，训练日安排力量训练，晚餐后继续工作。
- 每餐分别拍摄进食前和吃完后的照片，交给Claude估算实际摄入热量。
- AI也给出进食顺序建议，例如优先吃高蛋白菜肴。
- 他提到补充约25克蛋白质和5克肌酸，这是其个人方案，并非面向所有人的健康建议。
- 力量训练包括硬拉、深蹲等动作，训练日与非训练日交替。

</details>

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=197">把睡眠、摄入和训练汇总成日报</a> `03:17`

<details>
<summary>他尝试用同一个AI项目持续记录身体数据，而不是每次从零咨询。</summary>

- 他使用Oura Ring一类可穿戴设备查看睡眠和热量消耗指标，再把数据交给Claude Code。
- AI将估算摄入与消耗相比较；他提及的热量缺口和每日约140至150克蛋白质目标仅代表个人安排。
- Claude Code有专门的健康管理项目，每天结合睡眠、饮食和训练生成日报。
- 教练给每个训练动作拍视频，AI记录重量、次数和组数，例如每组12次、做三组。
- 记录用于观察渐进超负荷，即在适应后逐步增加训练负荷。
- 他举第一天训练消耗约275千卡为例，计划重复这一记录流程三个月再看结果。

</details>

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=314">先学习再实践，保留人的监督</a> `05:14`

<details>
<summary>AI承担整合与记录，但训练仍有教练参与。</summary>

- 正式训练前，他用约一周学习教程、了解补剂并准备记录设备。
- 他过去把蛋白补充与不恰当用药混为一谈，学习后改变了这一认识。
- 他认为仅靠日常饮食达到个人蛋白质目标较困难，因此把蛋白补充看作辅助，而不是替代全部食物。
- AI根据动作视频和训练日志反馈练到了哪些肌群、组数是否合适，教练同时提供现场指导。
- 全部照片、日报和Markdown记录保存在本地文件夹，形成可追溯的长期资料。
- 他希望后续换用其他AI时，新的工具能直接阅读README与历史文档接手，而不丢失上下文。

</details>

## 年轻人从零起步：借助AI认识自己与探索方向

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=483">预算有限时也可以开始使用AI</a> `08:03`

<details>
<summary>孙宇晨建议先选择负担得起的工具，而不是等待资源齐备。</summary>

- 主持人设定的问题是：如果重新回到20岁，没有人脉与资源，应怎样起步。
- 孙宇晨以自己大学时每月可支配资金不足1000元的经历说明，建议需要适应实际预算。
- 他建议低预算用户先选择智谱、Kimi等相对便宜或有免费额度的服务，而非直接购买昂贵方案。
- 节目中提及的套餐价格、免费活动和模型名称是访谈当时的说法，不应当作当前价格或可用性保证。
- 没有电脑也可以先用手机，将日程、学习和健康记录整理成文档。
- 他认为最重要的是开始把生活与工作流程数字化，让AI能够读取，而不必先买齐设备。

</details>

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=636">文档可迁移，比绑定单一服务更重要</a> `10:36`

<details>
<summary>把个人资料保存在可阅读的文件里，降低更换AI工具的成本。</summary>

- 他把学习、健身、课程与日程等都视为可以由AI辅助整理的对象。
- 使用Markdown保存资料，可以在不同服务之间迁移已有上下文。
- 预算紧张时可利用不同服务的免费额度；他本人付费主要是为了稳定性、减少切换时间。
- 他提及自己参与的B.ai作为聚合不同模型的例子，这是嘉宾的产品介绍。
- 对零基础用户，他强调先形成可执行的记录流程，而非把AI只当成偶尔聊天的工具。

</details>

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=723">认知、健康与面对质疑的心态</a> `12:03`

<details>
<summary>他用三种个人化概念概括改变思维、保持健康和独立行动。</summary>

- 孙宇晨把自己对金钱与财富自由的理解称为“孙学”，用升级操作系统比喻重新认识世界。
- 他把薄肌训练放在健康层面，而不只视为改善外表或吸引异性的手段。
- 他认为身体健康对长期发展具有基础性作用，健康失衡会拖慢工作与生活。
- 他所谓的“黄毛理论”，主要指面对嘲笑或非主流压力时，仍能专注自身发展并执行判断。
- 他预期新的训练和财富观念可能招致周围人的不理解，但这种预期属于其个人社会判断。
- 主持人将三者概括为认知、身体与心态的升级，而不是单纯追求金钱。
- 孙宇晨表达了极强的AI信任，并提及此前争议；这体现他的个人立场，不等于AI建议无需核验。

</details>

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=988">先积累个人数据，再讨论方向</a> `16:28`

<details>
<summary>具体选择应建立在个人情况之上，不存在适合所有人的同一答案。</summary>

- 主持人追问理念之后如何落实，孙宇晨建议先执行可负担的AI记录流程。
- 他建议用两至四个月积累健康、日常安排与现状资料，再让AI进行综合分析。
- 方向探索、收入来源和行动安排都可以结合这些数据讨论，而不是凭一句泛泛提问下结论。
- 他建议针对重要问题询问多个模型，用不同回答做比较。
- 聚合API能够让同一套本地资料接入不同模型，减少逐个重建上下文的麻烦。
- 他把多模型讨论比作获得几套备选方案，但并未提供证明其必然正确的验证方法。

</details>

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=1135">关注技术变化，并在一个兴趣方向持续钻研</a> `18:55`

<details>
<summary>AI辅助不能替代持续更新信息和选择具体领域。</summary>

- 除了问AI，他建议持续关注科技进步，因为新的机会随技术迭代不断出现。
- 他自己会查看X等渠道，也借助AI抓取动态，两种方式相互补充。
- 不必追踪所有领域；应结合兴趣选择一个方向，逐渐积累专业判断。
- 不可能在所有领域都成为专家，因此选择研究范围本身很重要。
- 决策不是一次性买卖，应该随着新数据不断调整，类似模型训练中的tuning。
- 他用每日睡眠与身体数据不断修正训练计划，说明反馈循环如何进入具体生活。

</details>

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=1267">与AI讨论分歧，而不是只获取结论</a> `21:07`

<details>
<summary>他以补剂认识的变化说明提问和追问原理的重要性。</summary>

- 孙宇晨把AI辅助比作自动驾驶，称大部分时间交给AI，少部分时间由自己调整。
- 当自己与AI意见不同时，他会进一步讨论，而非把首次回答当作讨论终点。
- 蛋白粉与肌酸的例子里，他曾有先入为主的担忧，后来通过追问原理改变理解。
- 主持人指出，嘉宾无法了解每个人的具体处境，因此更适合提供分析流程而非替每个人指定职业。
- 共通的起点是更新思维、关注健康和个人成长；其余决策应结合具体条件。

</details>

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=1411">从聊天转向可复用的个人知识工作流</a> `23:31`

<details>
<summary>最终目标是让AI持续利用本地资料，而不仅是增加聊天次数。</summary>

- 孙宇晨把自己早先“多与AI聊天”的建议进一步升级为让不同模型读取个人文档。
- 把文件保存在本地，可以由API或具备文件能力的工具持续使用。
- 他认为API并非不可跨越的技术门槛，不懂时可以让AI解释操作步骤。
- 不会建立Markdown文档或连接工具，也可以把学习这些步骤作为第一次实践。
- 主持人表示这会推动自己调整工作流，因为目前对AI的利用仍不充分。

</details>

## AI降低科研门槛：数学、生物与天文学

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=1503">年轻人的时间优势</a> `25:03`

<details>
<summary>孙宇晨认为AI降低多种成本，但人的寿命仍是无法轻易复制的资源。</summary>

- 主持人询问未来几年年轻人最值得投入的方向，孙宇晨先表达对年轻人的乐观。
- 他的判断是AI会让许多产品与能力变便宜，而可用于学习和体验的时间更加重要。
- 他明确承认AI尚未解决衰老与死亡问题，因此年轻本身具有时间优势。
- 他并不把机会限定在金融，而认为多个行业都会因AI产生新的进入路径。

</details>

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=1590">数学研究中的思路与知识网络</a> `26:30`

<details>
<summary>在他的解释中，AI可能让研究思路不再局限于少数导师和圈层。</summary>

- 孙宇晨以自己设立数学奖项为例，讨论AI如何改变研究者获取思路的方式。
- 他认为数学突破不只依靠解题能力，还依赖导师、研究网络以及对前沿路径的了解。
- 关于不同高校和数学竞赛成果的比较，是嘉宾的概括性判断，不能直接当作教育研究结论。
- 他把AI描述为能够汇集多种已有思路、比较方向并辅助探路的工具。
- 他也承认AI无法凭空给出人类尚未掌握的一切答案，以可控核聚变为例区分知识整合与真正突破。
- 他的核心期待是：原先受教育阶段或导师资源限制的年轻人，可以更早接触前沿问题。

</details>

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=1710">更早进入研究，不等于免除专业要求</a> `28:30`

<details>
<summary>他主张按问题和能力推进研究，而非等待固定学历阶段。</summary>

- 孙宇晨认为，只要能理解AI提供的思路，高中生或研究生也可能接触过去要到博士阶段才知道的研究路径。
- 他提及陶哲轩、爱因斯坦等年轻时已有成果的例子，强调数学与理论研究并不天然要求高龄。
- 他建议有兴趣的年轻人尽早研究具体问题，而不是把升学年级当作唯一时间表。
- 所谓与AI在短期内做出世界级成果，是他的乐观预测，并非已验证的普遍成功率。

</details>

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=1810">关于AI数学研究争议的转述</a> `30:10`

<details>
<summary>这一段是嘉宾对新闻和技术机制的推测，不应被写成已经核实的科研事实。</summary>

- 他转述一则涉及纽约大学数学研究者、OpenAI与NS方程研究思路的争议。
- 按他的叙述，研究者向模型提供思路后，机构通过agent和算力继续推进；他同时猜测系统可能持续吸收用户知识。
- 他提及约700万美元算力、数千agent与两天时间等数字，但节目未提供可核验来源。
- 这些说法不能据此认定NS方程相关难题已被解决，也不能据此推断具体产品会实时训练用户输入。
- 他借该故事表达的观点是，独特研究思路与强算力结合可能加速探索，原创贡献和知识归属也会受到关注。

</details>

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=1944">生物学与天文数据分析</a> `32:24`

<details>
<summary>他看好AI处理海量既有数据的潜力。</summary>

- 数学之外，他把生物学列为可能受益于AI的领域，但此处没有展开具体项目。
- 他提到自己曾向AI询问哪些学科可能出现突破，天文学是得到的答案之一。
- 其理由是望远镜积累大量数据，人工逐一处理繁重而枯燥。
- AI可能提高天文数据分析速度，但“很快取得决定性突破”仍是嘉宾的预期，而不是本段证实的成果。

</details>

## 全球商业、行业机会与先探图再决策

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=1985">商业机会应放在全球范围寻找</a> `33:05`

<details>
<summary>他的商业思路是识别客户需求与成本差异，而非局限于身边市场。</summary>

- 主持人把问题转向不想做学术、希望创造收入的年轻人，孙宇晨仍把AI作为主要工具。
- 他以不同地区AI服务价格存在差异为例，讨论连接供需的商业价值。
- 他提及token中转服务作为例子，并明确限定在合法环境中；这不代表任意跨区购买或转售都符合服务条款。
- 商机应全球发现，不应只把居住地周边的人看作客户。
- 需要结合个人长处与兴趣，而不是因为某地区有差价就立即投入。
- AI翻译可以缓解语言障碍，但他也认为学习一些基本语言仍有帮助。

</details>

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=2132">先说明你为客户创造了什么价值</a> `35:32`

<details>
<summary>判断商业模式的核心是客户为什么愿意使用和付费。</summary>

- 孙宇晨认为，商业首先要回答是否创造价值，而非仅找到看似热门的赛道。
- 若能让原来成本较高的客户以更低成本获得同等服务，便可能体现价值。
- 这一比较应放到全球范围，而不是只观察本市或本国的竞争。
- 他把中国制造与全球需求的连接视为传统行业也存在机会的理由。
- 实物产品之外，想法与服务也可以面向全球销售。
- 他希望年轻人以更大的客户池思考，而不是只在熟悉的小群体里竞争。
- 他还设想未来AI agent本身会成为服务需求方；节目中的人口与AI数量用于表达规模想象，并非经核验的预测。

</details>

### <a href="https://www.bilibili.com/video/BV1fcHD6cEw3/?t=2343">重大决定前先建立比较基准</a> `39:03`

<details>
<summary>买房、买车与择业的共同点，是先扩大样本再做判断。</summary>

- 他不建议年轻人过早凭有限信息认定自己只能做某件事，应该多学、多听、多看。
